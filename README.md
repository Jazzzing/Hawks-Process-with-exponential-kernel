# Hawks-Process-with-exponential-kernel

This project explores the Markov property of Hawkes processes with an exponential kernel through both theoretical analysis and numerical simulation. The implementation uses Python with NumPy for efficient computation and Matplotlib for visualization.

## Key Features
- **Analytical proof** of the Markov property for the joint process (N(t), λ(t|Hₜ))
- **Numerical simulation** using Ogata's modified thinning algorithm
- **Interactive Jupyter notebook** with complete implementation and visualizations
- **Applications** in finance, neuroscience, and event modeling

## Requirements
- Python 3.x
- NumPy
- Matplotlib
- Jupyter Notebook
